Convert a 3D model

Turns a downloaded glTF or STL model (?file=downloads/model.glb&name=saab340) into one like the others in models/: only the shell, no textures, white parts and dark parts (windows, tyres, propellers) as vertex colours, turned to x = right wing, y = nose, z = up, centred, 1 unit long, and thinned out to about &triangles=45000. &nose=+z and &up=+y say how the file lies if the page guesses wrong. In an STL print model the engraved windows become dark parts (&glass=0: not), and &props=4&propsize=0.085 adds propellers with so many blades and that radius (in aircraft lengths) to the tips of the two engines. The result is in window.result (a Blob) and offered as a download. Needs a local web server.
